# Yapay Zeka Destekli Akıllı Depo ve Filo Tedarik Zinciri Yönetim Sistemi

Bu proje, lojistik sektöründe depo verileri ile saha operasyonları arasındaki kopukluğu gidermek ve operasyonel verimliliği artırmak amacıyla geliştirilen "Akıllı Lojistik" ekosistemidir. Sistem, ürün girişinden son teslimata kadar olan süreci bütünleşik bir yapıda yönetir.
## 📌 Proje Kapsamı ve Sorun Tanımı

Lojistik süreçlerinde manuel yönetimden kaynaklanan insan hataları, sipariş gecikmelerine ve verimsiz rota kullanımına neden olmaktadır. Bu proje; envanter yönetimi, araç takibi ve yapay zeka tabanlı analizleri tek bir merkezde toplayarak operasyonel şeffaflık sağlamayı hedefler.
## 🚀 Temel Özellikler ve Yenilikçi Yönler

    LLM Destekli Karar Mekanizması: Sadece veri kaydeden bir sistem değil, AI API entegrasyonu sayesinde verileri yorumlayan bir asistana sahiptir.

    Akıllı Analiz: Yöneticiye; stok öngörüsü, araç verimliliği ve stratejik stok planlaması gibi konularda ham veriyi analiz ederek öneriler sunar.

    Gerçek Zamanlı Saha Verisi: Mobil uygulama üzerinden şoför ve depo personelinin anlık veri girişi yapmasına olanak tanır.

    Dinamik API Mimarisi: İleride IoT cihazları (akıllı raflar, GPS takip cihazları) ile kolayca entegre olabilecek esneklikte tasarlanmıştır.

## 🛠 Teknoloji Yığını

    Backend: Python / Django & Django REST Framework (DRF).

    Mobile: Kotlin (Android).

    Yapay Zeka: Google AI for Developers / Gemini API. / Groq AI, Groq API

    Veri Yönetimi: Merkezi veri yapısı ve senkronize API mimarisi.

## 👥 Paydaşlar ve Hedef Kitle

    İç Paydaşlar: Depo yöneticileri, depo personeli ve filo şoförleri.

    Dış Paydaşlar: KOBİ ölçekli işletmeler ve butik lojistik/dağıtım şirketleri.

    Son Kullanıcı: Daha hızlı ve şeffaf hizmet alan müşteriler.
